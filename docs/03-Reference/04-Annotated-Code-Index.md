# Annotated Code Index

This pack adds commented code directly inside **every one of the 18 API/system topics** and **all 26 week/class lessons**. Topic guides are complete study guides; class files include a focused code lab in section **9A**.

## Important provenance

- The curriculum is derived from the instructor-provided README and Project 01 contract.
- The original source repository was **not uploaded** and the public URL yielded no readable source files.
- Snippets are original, illustrative reference implementations, **not claims of exact project code** or a drop-in tested application.
- Paths such as `src/services/auth.js` correspond to the documented areas, but symbol names and schema subfields require verification against actual source.
- Some examples intentionally demonstrate a single layer; do not use them without sibling route validation, error translation, and account/role checks.

## Recommended order

Start with app lifecycle, models and authentication. Then work through role/owner protection, categories, ads, media, search, private interactions, moderation, tests, and readiness. For each excerpt, map route → validator/auth → service → schema/provider → response and write both success and denied test cases.
