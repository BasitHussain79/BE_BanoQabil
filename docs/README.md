# OLX Clone Marketplace — Project 01 Markdown Curriculum

**Node.js 24 · Express 5 · MongoDB/Mongoose · Email OTP · JWT · RBAC · Cloudinary · Tests**

**Based on:** [Project 01 page](https://basith.dev/learn/backend-development/project-01) and the complete README supplied by the instructor. These are **modular study materials**, not a replacement for the application source.

## What is in this pack?

- **18 individually authored topic guides** for API functionality and underlying system concepts.
- **26 standalone Markdown class handouts**, exactly two classes per week for 13 weeks, with the same **14 teaching blocks** as the original course.
- Project review, quick start, architecture map, persona business flows, full technology stack, canonical route inventory, limits/status reference, and source-verification checklist.

**Source-integrity note:** The public project page was accessible but did not provide readable source content to the inspection tool. The actual repository files were not supplied, so this pack reproduces the shared README's documented behavior and flags details that need code verification. No tests were executed in this documentation task.

## Non-goals (not implemented in this backend)

No React/Next.js client, dashboards, checkout/payments, refresh token rotation/revocation, password reset, WebSockets, production deployment pipeline, Docker, analytics dashboards, or infrastructure monitoring. Buyer/seller are user personas rather than persisted roles.

## How to use as an instructor

1. Assign that week's two class handouts and one or more matching API topic guides.
2. Walk through routes and validators in the **actual project source**, then make requests in Postman.
3. Collect status, safe response, database effect, and negative-case evidence for each assignment.
4. Use the source verification checklist before publishing examples as code-verified documentation.

## Response contract

- Successful `/api` operations: `{{ "data": ... }}`
- Error responses: `{{ "error": "safe public message" }}`
- `GET /health`: direct `{{ "status": "OK", "uptime": ... }}`
